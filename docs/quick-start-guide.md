# Case Management System - Quick Start Guide

This quick start guide will help you get up and running with the Case Management System quickly.

## Accessing the System

1. Open your web browser and navigate to: https://case-management.bozza.au
2. Log in with your credentials or register a new account

## Key Features Overview

### Creating a Case
1. Click "Create New Case" on the dashboard
2. Enter case title, description, type, and priority
3. Click "Create Case"

### Adding Evidence
1. Open a case and click "Add Evidence"
2. Select evidence type (document, photo, video, audio, other)
3. Fill in details and upload file
4. Click "Add Evidence"

### Viewing the Timeline
1. Open a case and click the "Timeline" tab
2. View evidence chronologically
3. Use zoom controls to focus on specific periods

### Using AI Analysis
1. Open a case and click the "Analysis" tab
2. View automatically generated:
   - Case summary
   - Evidence connections
   - Investigative leads
   - Timeline analysis

### Generating Reports
1. Open a case and click the "Reports" tab
2. Select report type
3. Click "Generate Report"
4. Export as PDF or other formats

## Tips for Best Results

- Provide detailed case descriptions for better AI analysis
- Include accurate date/time information with all evidence
- Tag evidence appropriately for better organization
- Check the Analysis tab regularly for new insights
- Use the search function to quickly find specific evidence

## Getting Help

If you need assistance, click the "Help" icon in the top-right corner or refer to the comprehensive User Guide in the Help section.

Happy investigating!
