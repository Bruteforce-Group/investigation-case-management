## Getting Started

### Accessing the System

1. Open your web browser and navigate to the application URL (e.g., https://case-management.bozza.au)
2. You will be directed to the login page

### Creating an Account

1. Click on the "Register" link on the login page
2. Fill in your details:
   - Full name
   - Email address
   - Password (must be at least 8 characters with a mix of letters, numbers, and special characters)
3. Click "Register" to create your account
4. You will receive a confirmation email (if email verification is enabled)

### Logging In

1. Enter your email address and password on the login page
2. Click "Login" to access the system
3. If you forget your password, click "Forgot Password" and follow the instructions

## Dashboard Overview

The dashboard is your central hub for managing all your cases and activities.

### Key Dashboard Elements

- **Case Overview**: Displays all your active cases with key information
- **Recent Activity**: Shows recent updates to your cases
- **Quick Actions**: Provides shortcuts to common tasks
- **Notifications**: Alerts you to important updates and system messages

### Navigation

- The main navigation menu is located on the left side of the screen
- Key sections include:
  - Dashboard
  - Cases
  - Evidence
  - Reports
  - Account Settings

## Case Management

### Creating a New Case

1. From the dashboard, click the "Create New Case" button
2. Fill in the case details:
   - Case title
   - Case description (provide as much detail as possible for better AI analysis)
   - Case type (e.g., Missing Person, Homicide, Theft)
   - Priority level
   - Tags (optional)
3. Click "Create Case" to save

### Viewing Case Details

1. Click on any case from the dashboard to view its details
2. The case detail page includes:
   - Case summary
   - Evidence list
   - Timeline view
   - AI analysis
   - Reports section

### Editing Case Information

1. From the case detail page, click the "Edit" button
2. Update any case details as needed
3. Click "Save Changes" to update the case

### Closing a Case

1. From the case detail page, click the "Close Case" button
2. Add any closing notes
3. Confirm the action

## Evidence Management

### Adding Evidence

1. From the case detail page, click the "Add Evidence" button
2. Select the evidence type:
   - Document
   - Photo
   - Video
   - Audio
   - Other
3. Fill in the evidence details:
   - Title
   - Description
   - Date/time (when the evidence was collected or created)
   - Location (if applicable)
4. Upload the evidence file (if applicable)
5. Click "Add Evidence" to save

### Viewing Evidence

1. From the case detail page, click on any evidence item in the evidence list
2. The evidence detail view includes:
   - Evidence information
   - File preview (for supported file types)
   - Related evidence (identified by AI)
   - Timeline position

### Editing Evidence

1. From the evidence detail view, click the "Edit" button
2. Update any evidence details as needed
3. Click "Save Changes" to update

### Deleting Evidence

1. From the evidence detail view, click the "Delete" button
2. Confirm the deletion
3. Note: Deleting evidence will remove it from the timeline and may affect AI analysis

## Timeline Visualization

### Viewing the Timeline

1. From the case detail page, click the "Timeline" tab
2. The timeline displays all evidence chronologically
3. Each evidence item is represented by a node on the timeline

### Timeline Features

- **Zoom**: Use the zoom controls to focus on specific time periods
- **Filters**: Filter the timeline by evidence type, date range, or other criteria
- **Gaps Analysis**: The system highlights potential gaps in the timeline
- **Evidence Details**: Click on any timeline node to view the associated evidence

### Timeline Updates

- The timeline automatically updates when new evidence is added
- Real-time updates ensure you always see the most current information

## AI Analysis Features

### Case Summary

- The AI automatically generates a comprehensive case summary based on all evidence
- The summary updates in real-time as new evidence is added
- Access the summary from the "Analysis" tab on the case detail page

### Evidence Connections

1. The AI identifies potential connections between different pieces of evidence
2. View connections from the "Connections" section of the Analysis tab
3. Each connection includes:
   - Connected evidence items
   - Relationship type
   - Confidence score
   - Explanation of the connection

### Investigative Leads

1. The AI generates potential investigative leads based on the evidence
2. View leads from the "Leads" section of the Analysis tab
3. Each lead includes:
   - Description
   - Priority level
   - Related evidence
   - Suggested actions

### Timeline Analysis

- The AI analyzes the timeline for inconsistencies and gaps
- View timeline analysis from the "Timeline Analysis" section of the Analysis tab
- The system provides suggestions for addressing identified issues

## Reports and Exports

### Generating Reports

1. From the case detail page, click the "Reports" tab
2. Select the report type:
   - Case Summary Report
   - Evidence Summary
   - Timeline Report
   - Analysis Report
   - Comprehensive Case Report
3. Configure report options (if applicable)
4. Click "Generate Report"

### Exporting Reports

1. After generating a report, click the "Export" button
2. Select the export format:
   - PDF
   - Word Document
   - HTML
3. The report will be downloaded to your device

### Scheduled Reports

1. To set up scheduled reports, click "Schedule" after generating a report
2. Select the frequency (daily, weekly, monthly)
3. Choose recipients
4. Click "Save Schedule"

## Account Management

### Updating Profile Information

1. Click on your profile icon in the top-right corner
2. Select "Profile Settings"
3. Update your information as needed
4. Click "Save Changes"

### Changing Password

1. Go to Profile Settings
2. Click the "Change Password" tab
3. Enter your current password
4. Enter and confirm your new password
5. Click "Update Password"

### Notification Preferences

1. Go to Profile Settings
2. Click the "Notifications" tab
3. Configure your notification preferences
4. Click "Save Preferences"

## Troubleshooting

### Common Issues

#### Login Problems

- Ensure you're using the correct email and password
- Check if Caps Lock is enabled
- Try resetting your password

#### Evidence Upload Issues

- Check that the file is in a supported format
- Ensure the file size is within limits (typically 50MB)
- Try a different browser if problems persist

#### Timeline Display Problems

- Ensure all evidence has proper date/time information
- Try refreshing the page
- Clear your browser cache

### Getting Help

- Click the "Help" icon in the top-right corner for context-sensitive help
- Email support at support@case-management.bozza.au
- Check the knowledge base for additional resources
